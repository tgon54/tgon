# AI-MoCap: التقاط الحركة من فيديوهات الذكاء الاصطناعي مع التصحيح الذكي

تأخذ الأداة **فيديو AI واحداً يحتوي على شبكة زوايا** (مثلاً 2×2: أمام / يمين / خلف / يسار)، وتُخرج حركة ثلاثية الأبعاد مصحَّحة علمياً وجاهزة للعبتك:
BVH وFBX، وJSON مع عارض ويب، وCSV/NPY، وتقرير جودة علمي.

## التثبيت (Windows / Linux مع NVIDIA)

انقر نقراً مزدوجاً على **`install.bat`**. يثبّت كل المكتبات، ويختار تلقائياً نسخة GPU إذا وُجدت بطاقة NVIDIA. (`start_ui.bat` يشغّله تلقائياً في أول مرة.)

- يحتاج `onnxruntime-gpu` إلى CUDA 12 وcuDNN 9. إذا ظهر خطأ CUDA، ثبّت `onnxruntime` العادي (يعمل على المعالج لكنه أبطأ).
- عند التشغيل الأول تُنزَّل نماذج RTMPose تلقائياً (حوالي 200 MB).

## الواجهة (الأسهل)

انقر نقراً مزدوجاً على **`start_ui.bat`**، فتُفتح الواجهة في المتصفح على `http://127.0.0.1:8642`. كل شيء يعمل على حاسوبك، ولا يُرفع أي ملف إلى الإنترنت.

1. **الفيديو:** اسحبه إلى الصفحة.
2. **الزوايا:** تُكتشف الشبكة تلقائياً. يمكنك سحب الخطوط لضبطها، أو الضغط على لوحة لاستبعادها، أو اختيار شبكة جاهزة. الاتجاهات تلقائية افتراضياً، ويمكنك تحديدها يدوياً.
3. **الإعدادات:** طول الشخص، ودقة الكشف، والمعالج.
4. **ابدأ:** تظهر نسبة التقدم والمراحل والسجل مباشرة، ويمكنك الإلغاء.
5. **النتائج:** مقاييس قبل وبعد، والعارض ثلاثي الأبعاد، والتقرير العلمي، وتنزيل كل الملفات.
6. **تعديل التصحيح وإعادة التشغيل:** يعيد التصحيح بإعدادات جديدة دون إعادة الكشف، فيكون سريعاً.

تُحفظ الفيديوهات والنتائج في مجلد `aimocap_workspace` بجانب الأداة.

## التشغيل من سطر الأوامر

```bash
python -m aimocap my_ai_video.mp4 out --height 1.75
```

| الخيار | المعنى |
|---|---|
| `--grid 2x2` | حدّد الشبكة يدوياً إذا فشل الكشف التلقائي |
| `--panels 0,1,2,3` | اللوحات المستخدمة (بالترتيب صفاً صفاً) |
| `--yaws 0,90,180,270` | اتجاه كل لوحة بالدرجات. الافتراضي تلقائي: تُجرَّب الاتجاهات ويُختار الأفضل |
| `--height 1.75` | طول الشخص بالمتر، ويحدد المقياس الحقيقي |
| `--mode performance` | أدق نموذج (RTMPose-x). البدائل: `balanced` و`lightweight` |
| `--max-frames 300` | لاختبار سريع على أول 300 إطار |

نتائج الكشف ثنائي الأبعاد تُحفَظ في `out/detections_2d.npz`، فإعادة التشغيل بإعدادات أخرى فورية.

### التصدير إلى Unreal Engine (UE4 / UE5) مع حركة اليدين

كل معالجة تُنتج تلقائياً `motion_UE4.fbx` (هيكل UE4 Mannequin) و`motion_UE5.fbx` (هيكل UE5 Manny) دون الحاجة إلى Blender أو إعادة استهداف.
في Unreal: Import ← اختر الملف ← Skeleton = `UE4_Mannequin_Skeleton` (أو `SK_Mannequin` في UE5) ← ألغِ Import Mesh.

```bash
python -m aimocap.unreal out --target ue4            # أو ue5 أو ملف FBX لهيكل بأسماء UE
python -m aimocap.unreal out --target ue4 --root-motion
```

**مجلد المانيكانات `mannequins/`:** ضع فيه أي شخصية `.fbx` بأسماء عظام Unreal (Manny وQuinn وأجسام MetaHuman…)
فتصبح هدفاً للتصدير بوضعيتها ونِسَبها: تُنتج المعالجة `motion_<اسم الملف>.fbx`، وتظهر في منظّف الخط الزمني،
وفي سطر الأوامر `--target <اسم الملف>` أو `--target all` (والقائمة: `python -m aimocap.unreal --list`).

### منظّف الخط الزمني (Timeline Cleaner)

شغّل `start_cleaner.bat` (أو افتح `http://127.0.0.1:8642/cleaner`). يعرض الحركة على خط زمني مع كشف تلقائي للمشاكل
(القفزات/الأخطاء، الارتعاش، ضعف التتبع، انزلاق القدم، فقدان تتبع اليد)، وأدوات: إصلاح الخلل، التنعيم، تثبيت الوضعية، تثبيت القدم،
إرخاء اليدين، القص، دمج الحلقة، التنظيف التلقائي، تراجع/إعادة. ثم زر **Export FBX** إلى Unreal.
التعديلات غير مدمّرة وتُحفظ في `clean_edits.json`. من سطر الأوامر: `python -m aimocap.timeline out --auto 0.5 --target ue4`.

### تحويل BVH إلى FBX عبر Blender (اختياري)

```bash
blender -b -P blender_bvh_to_fbx.py -- out/motion.bvh out/motion.fbx
```

## كيف تولّد فيديو AI مناسباً (أهم خطوة)

1. **فيديو واحد يحتوي على كل الزوايا.** هذا يضمن التزامن ويحسّن الاتساق. لا تولّد كل زاوية في فيديو منفصل.
2. **شبكة 2×2 بخطوط فاصلة واضحة**، والترتيب: أمام، يمين، خلف، يسار.
3. **إنسان واقعي بملابس ضيقة متباينة مع الخلفية**، والجسم كاملاً من الرأس إلى القدمين في كل لوحة.
4. **كاميرات ثابتة** بلا حركة ولا تقريب، وأرضية مستوية واضحة.
5. **حركة واحدة واضحة** مدتها 4–10 ثوانٍ.

مثال برومبت:

> A 2x2 split-screen grid video with thin white borders. The same realistic athlete in tight dark clothing performs [ACTION], filmed simultaneously by four static cameras: top-left front view, top-right right-side view, bottom-left back view, bottom-right left-side view. Full body visible head to toe in every panel, plain light gray studio, flat floor, no camera motion, no cuts.

## التصحيح الذكي: ماذا يفعل

1. **فحص أخطاء AI ثنائي الأبعاد:** يرفض النقاط التي تقفز أو تتشوّه، والإطارات المشوّهة كلها.
2. **معايرة ذاتية:** جسم الشخص نفسه هو لوح المعايرة. تُستخدم bundle adjustment لتقدير موقع كل كاميرا وعدستها، مع اختيار ترتيب الزوايا تلقائياً.
3. **تصحيح تبديل اليمين واليسار** لكل زاوية ولكل طرف، بخوارزمية Viterbi.
4. **تثليث قوي:** يستبعد الزاوية "المهلوسة" التي لا تتفق هندسياً مع البقية.
5. **إكمال الفجوات وإزالة القفزات**، ثم مرشّح Butterworth صفري الطور.
6. **مستوى الأرض والمقياس والتوجيه:** الأرض عند y=0، والوحدات بالمتر، والشخص يواجه +Z.
7. **قيود تشريحية:** أطوال عظام ثابتة ومتناظرة، ومنع انثناء الركبة للخلف.
8. **قيود فيزيائية:** تثبيت القدم أثناء التلامس (بلا انزلاق)، ومنع اختراق الأرض، وحساب مركز الثقل.

## التحقق العلمي

```bash
python test_synthetic.py synthetic_out
```

الاختبار يولّد حركة معروفة، ويُسقطها على 4 كاميرات تختلف عن الافتراض الاسمي (زوايا 98° و175° و276°، ومسافات وعدسات مختلفة). ثم يضيف عيوب AI: ضجيج، واختفاء نقاط، وتبديل يمين/يسار، وتشوّهات، وزاوية مهلوسة لمدة 12 إطاراً. وأخيراً يقيس الخطأ مقارنة بالحقيقة.

| المرحلة | متوسط الخطأ (MPJPE) | p95 |
|---|---|---|
| خام (كاميرات اسمية + DLT عادي) | 64.9 mm | 165 mm |
| بعد المعايرة الذاتية والتثليث القوي | 5.3 mm | 10.3 mm |
| **نهائي بعد كل التصحيحات** | **4.2 mm** | **9.1 mm** |

- الزوايا المقدَّرة: 98.3° و176.2° و275.7° (الحقيقية 98° و175° و276°).
- تذبذب أطوال العظام: من 41.7% إلى 0.02%.
- انزلاق القدم: من 1.05 m/s إلى 0.
- ملف BVH متحقَّق منه بمحلل مستقل: الخطأ أقل من 1 سم.

## حدود يجب معرفتها

- الدقة الحقيقية تعتمد على **اتساق الفيديو المولَّد بين الزوايا**. الأداة تكشف التناقض وتخفف أثره وتقيسه في التقرير، لكنها لا تستطيع اختراع معلومات غير موجودة.
- الأداة مصممة لشخص واحد في كل لوحة.
- اليدان: 21 نقطة لكل يد من مقاطع حول الرسغ. اليد في فيديو AI صغيرة غالباً، لذلك يُمزج التتبع مع وضعية يد طبيعية مرتخية حسب الثقة، مع حدود تشريحية للمفاصل. عطّلها بـ `--no-hands`.
